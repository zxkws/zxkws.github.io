# 微前端架构说明

## 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                        主应用 (main-app)                      │
│                   http://localhost:3000                       │
│                                                               │
│  ┌─────────────────────────────────────────────────────┐    │
│  │              统一导航和菜单                           │    │
│  │  - 主应用静态菜单                                    │    │
│  │  - v-app 菜单（动态获取）                            │    │
│  │  - textDiff 菜单（动态获取）                         │    │
│  └─────────────────────────────────────────────────────┘    │
│                                                               │
│  ┌───────────────────┐  ┌───────────────────┐               │
│  │   主应用路由       │  │  微应用容器        │               │
│  │   /               │  │                   │               │
│  │   /about          │  │  加载微应用内容    │               │
│  │   /login          │  │  (无导航栏)       │               │
│  └───────────────────┘  └───────────────────┘               │
└─────────────────────────────────────────────────────────────┘
                              ↑
                              │ 动态加载
                              │
        ┌────────────────────┴────────────────────┐
        │                                         │
┌───────▼────────┐                     ┌────────▼────────┐
│  v-app 微应用   │                     │  textDiff 微应用 │
│  :5173         │                     │  :5174          │
│                │                     │                 │
│  暴露菜单配置   │                     │  纯静态应用      │
│  隐藏自己的导航 │                     │                 │
└────────────────┘                     └─────────────────┘
```

## 运行模式对比

### 模式一：在主应用中运行（微前端模式）

```
用户访问: http://localhost:3000/v-app
                    ↓
            主应用加载 v-app
                    ↓
        v-app 检测到 isMicroApp = true
                    ↓
        ┌───────────────────────────┐
        │ 1. 隐藏自己的导航和菜单     │
        │ 2. 暴露菜单到全局变量       │
        │ 3. 主应用统一显示菜单       │
        └───────────────────────────┘
```

**用户看到的界面：**

```
┌────────────────────────────────────────┐
│  [Logo]  Home  About  Login  Vue应用 ▼  │ ← 主应用导航
├──────┬─────────────────────────────────┤
│ Home │                                 │
│ About│                                 │
│ Login│      v-app 内容区                │
│      │    （无自己的导航）               │
│ Vue应用│                                 │
│  ├导航 │                                 │
│  ├Todo│                                 │
│  └账户 │                                 │
└──────┴─────────────────────────────────┘
```

### 模式二：独立访问（独立模式）

```
用户访问: http://localhost:5173
                    ↓
        直接访问 v-app (不在主应用中)
                    ↓
        isMicroApp = false
                    ↓
        ┌───────────────────────────┐
        │ 1. 显示完整的导航和菜单     │
        │ 2. 不暴露菜单到全局         │
        │ 3. 独立的路由系统           │
        └───────────────────────────┘
```

**用户看到的界面：**

```
┌────────────────────────────────────────┐
│  [v-app Logo]  导航  Todo  账户  设置   │ ← v-app 自己的导航
├──────┬─────────────────────────────────┤
│ 导航  │                                 │
│ Todo │                                 │
│ 账户  │      v-app 内容区                │
│ 排名  │    （完整功能）                  │
│      │                                 │
└──────┴─────────────────────────────────┘
```

## 菜单通信机制

### 数据流向

```
微应用 (v-app)
    │
    │ 1. 定义菜单配置
    ↓
menuConfig.ts
    │
    │ 2. exposeMenuToHost()
    ↓
window.__MICRO_APP_MENUS__
    ↑
    │ 3. 读取菜单配置
    │
主应用 (main-app)
    │
    │ 4. 整合并渲染
    ↓
统一导航菜单
```

### 全局变量结构

```typescript
window.__MICRO_APP_MENUS__ = [
  {
    appName: 'v-app',
    menus: [
      { name: '导航列表', path: '/v-app/navList', icon: '🏠' },
      { name: 'Todo', path: '/v-app/todo', icon: '✅' },
      { name: '账户管理', path: '/v-app/account', icon: '👤' },
    ],
  },
  // ... 其他微应用
];
```

## 路由策略

### 主应用路由

```typescript
/                    → 主应用首页
/about              → 主应用关于页
/login              → 主应用登录页
/curlconverter      → 内嵌组件（非微应用）
/v-app/*            → 加载 v-app 微应用
/textdiff/*         → 加载 textDiff 微应用
```

### v-app 微应用路由（basename: /v-app）

```typescript
/v-app/             → 微应用首页
/v-app/navList      → 导航列表
/v-app/todo         → Todo 页面
/v-app/account      → 账户管理
/v-app/llm-ranking  → LLM 排名
```


## 生命周期

### 微应用生命周期

```
bootstrap()     →  初始化（空实现）
    ↓
mount()         →  挂载微应用
    │               - 创建 Vue 实例
    │               - 配置路由
    │               - 暴露菜单（如果是微前端模式）
    │               - 挂载到容器
    ↓
运行中           →  响应用户交互
    ↓
unmount()       →  卸载微应用
                    - 销毁 Vue 实例
                    - 清理状态
```

## 关键特性

### ✅ 技术栈无关

主应用是 React，微应用可以是 Vue、Angular 或纯 JS

### ✅ 独立部署

每个应用可以独立开发、构建、部署

### ✅ 统一体验

主应用统一管理路由、菜单、权限

### ✅ 环境隔离

使用 ice-stark 的沙箱机制隔离 JS、CSS

### ✅ 热更新支持

开发环境支持主应用和微应用同时热更新

## 最佳实践

1. **路径规范**：微应用路径必须包含 basename（如 `/v-app/`）
2. **状态隔离**：微应用状态不应该依赖主应用
3. **通信机制**：通过全局事件或约定的全局变量通信
4. **错误边界**：每个微应用应该有自己的错误处理
5. **版本管理**：使用语义化版本管理微应用
