# 知识中台微应用开发方案

## 1. 里程碑拆解

| 阶段       | 工作项                                                     | 产出                                             |
| ---------- | ---------------------------------------------------------- | ------------------------------------------------ |
| 需求澄清   | 补齐需求/技术评审/开发方案文档                             | 《需求说明》《技术评审》《开发方案》《API 规格》 |
| 架构初始化 | 创建 `knowledge-hub-app` 包、配置 Vite、微前端生命周期     | 新微应用工程骨架，可独立运行                     |
| 功能开发   | 实现六大 Tab 页面、指标卡片、表格、时间轴、API Schema 视图 | 可交互的前端界面，数据来自 mock                  |
| 集成联调   | 更新主站菜单、配置中心、根脚本；本地联调验证               | `/app/knowledge-hub` 正常访问，构建通过          |
| 文档收尾   | 补充 README、后端接口定义、运营说明                        | 完整交付材料                                     |

## 2. 开发任务明细

1. **工程初始化**
   - 新建 Vite + React + TS 项目，设定 `base`、端口、跨域头。
   - 配置 `@ice/stark-app` 生命周期，支持主站挂载与 standalone 模式。
2. **领域模型与 Mock**
   - 定义 `types/knowledge.ts`，覆盖知识空间、Pipeline、GraphRAG、API Schema 等。
   - 编写 `data/mock.ts`，输出指标、资产、缺陷、API 定义。
3. **界面实现**
   - 顶部头部 + Tab 导航。
   - 各业务区块：指标卡、表格、Pipeline、时间轴、手册卡片、API JSON 展示。
   - 统一暗色玻璃拟态风格，响应式布局。
4. **集成适配**
   - 更新主站菜单 `menuConfig.ts`。
   - 配置中心 `micro-apps.json` 新增微应用。
   - 根脚本加入 `dev:knowledge-hub` 与构建链路。
5. **验收与交付**
   - 运行 `pnpm --filter knowledge-hub-app build` 确保通过。
   - 自测 Tab 切换无报错，mock 数据渲染正确。
   - 提交文档与代码。

## 3. 风险与缓解

- **UI 信息量大**：通过模块化组件、滚动容器避免页面过长；必要时分栏呈现。
- **未来接入真实数据**：提前定义类型与接口，mock 数据与真实结构对齐。
- **微前端兼容性**：遵循现有微应用生命周期模式，保持 `setLibraryName` 与 `mount/unmount` 实现。

## 4. 后续扩展建议

- 引入实时数据：接入 GraphQL 或 REST API，结合 SWR/React Query 做缓存。
- 多模态可视化：补充缩略图、音频波形、图谱可视化组件。
- 运营动作：在缺陷列表中新增“派单”“标记完成”等交互，联动后端。
- 指标监控：接入 Prometheus/Grafana 数据源，展示实时曲线。
