# 知识中台微应用需求说明书

## 1. 背景与目标

- 现有主站缺乏一个集中展示跨模态知识资产的门户，无法直观呈现文本知识库、多模态知识库与 GraphRAG 能力。
- 运营团队需要统一的治理面板来查看知识入库链路、质量缺陷、运行态指标以及接口说明。
- 本微应用旨在提供“知识 Hub”体验，覆盖从知识空间管理、入库编排、GraphRAG 推理到 API 对接的端到端视图。

## 2. 使用角色与关键诉求

| 角色        | 主要诉求                                             |
| ----------- | ---------------------------------------------------- |
| 平台管理员  | 快速浏览知识资产规模、模态分布、检索性能；配置新空间 |
| 知识运营    | 查看入库管道、实时缺陷、治理手册，执行补救动作       |
| 模型工程师  | 查看 GraphRAG 运行态、节点关系模板、推理链路指标     |
| 后端/集成方 | 获取服务端 API Schema、了解能力边界和错误码          |

## 3. 业务范围

- **文本知识库**：展示入库 pipeline 阶段、调度策略、成功率、检索质量指标。
- **多模态知识库**：覆盖视频/音频/图像资产的标准化流程、资产标签与治理状态。
- **GraphRAG**：提供图谱节点/关系模板、运行态任务列表、性能指标。
- **运营治理**：展示质量缺陷、责任人、修复建议以及标准化手册。
- **API / SDK**：列出核心后端服务、接口定义、请求/响应 schema、错误码。

## 4. 功能需求

1. **总览页**
   - 指标卡：知识空间数量、资产规模、图谱规模、检索延迟等。
   - 知识空间表格：显示模态、文档数、Token 数、召回、延迟、状态、责任人。
2. **文本知识库页**
   - Pipeline 列表：阶段信息、负责人、配置详情、调度与成功率。
   - 检索评估：Recall、Latency、Coverage 等指标对比基线和目标。
3. **多模态知识库页**
   - Pipeline：涵盖视频帧解析、音频语义提取、多模态图谱对齐等阶段。
   - 资产工作台：展示资产模态、维度、标签、更新时间、处理状态。
4. **GraphRAG 编排页**
   - Graph pipeline 阶段展示。
   - 节点类型/关系模板：说明语义、示例。
   - 推理运行态：最近任务、延迟、Hops、推理 token。
5. **运营与治理页**
   - 质量缺陷列表：严重度、责任人、修复建议。
   - 标准化手册：SOP 列表，步骤说明。
6. **API / SDK 页**
   - 后端服务列表：服务描述、Base Path。
   - 接口细节：Method、Path、摘要、请求/响应 schema、错误码。

## 5. 非功能需求

- **性能**：静态数据渲染，保证单页交互渲染时间 < 200ms。
- **可扩展性**：数据结构可替换为实时 API 返回结果。
- **一致性**：遵循主站暗色调微玻璃拟态风格，符合现有微应用架构。
- **可维护性**：数据结构、接口 schema 以类型定义约束，便于后续接入真实后端。

## 6. 数据与接口

- 所有数据暂使用 mock 数据，结构与未来 API 对齐。
- 后端接口分为 `knowledge-core-service` 与 `graph-reasoner-service`，详见《技术评审》与《API 规格》。

## 7. 交互与动线

- 顶部 Tab 切换不同业务域；按钮提供“新建知识空间”“版本切换”等入口。
- 数据展示组件采用卡片 + 表格 + 时间轴组合，满足概览与深度信息需求。

## 8. 验收标准

- 进入 `/app/knowledge-hub` 路由能加载微应用并显示总览页。
- 各 Tab 数据渲染正确，无控制台报错。
- API 页面展示完整 schema 与错误码信息。
- 文档齐备：需求、技术评审、开发方案、API 规格均在 `docs/knowledge-hub` 下。
